# PRD — Passage

## 1. 문제 정의
독서의 경험은 빠르게 흐려진다. *그 책을 어디서, 어떤 계절에, 얼마나 몰입해 읽었는지* 는 사실
책의 내용만큼이나 소중한 기억이지만, 어디에도 남지 않는다.

기존 독서 앱은 대부분 **관리·측정·목표 달성**에 초점을 둔다. 연간 목표, 읽은 권수, 스트릭, 랭킹은
독서를 성취 과제로 바꾸고 사용자를 압박한다. 그 결과 독서는 "해치워야 할 일"이 된다.

## 2. 해결 방법
Passage는 독서를 **기록이 아니라 회상**으로 다룬다.
독서를 마치면 조용히 묻는다 — **"어디서 읽으셨나요?"**
그 순간의 책 · 장소 · 시간 · 사진이 하나의 **기억(memory)** 으로 저장되고,
나중에 책별 · 장소별로 그 기억들을 되돌아본다.

> **Memory over Productivity** — 더 많이 읽게 만드는 앱이 아니라, 읽은 순간을 오래 간직하는 앱.

## 3. 사용자
- 독서를 삶의 일부로 여기고, 그 경험을 **기억으로 남기고 싶은** 사람
- 목표·경쟁·통계보다 **분위기와 회상**을 중시하는 사람
- "올해 30권" 같은 압박이 아니라, "그 카페에서 읽던 그 책"을 떠올리고 싶은 사람

명시적 비대상: 독서량을 극대화하려는 사용자, 소셜 공유·랭킹을 원하는 사용자.

## 4. 핵심 개념
- **Book** — 읽는 대상. 검색 / ISBN / 수동 등록으로 추가.
- **Reading Session** — 한 번의 독서 행위. **앱의 원자 단위이자 Source of Truth.**
  시작~종료 시간, (선택)시작·종료 페이지, 연결된 책과 장소를 가진다.
- **Place** — 읽은 곳. 이름 · (선택)위치 · (선택)사진. 기존 장소 재사용 또는 새로 생성.
- **Memory** — Session이 책·장소·시간·사진과 엮여 만들어지는 하나의 회상 단위(별도 저장 X, Session에서 파생).

## 5. 기능 (MVP)
### Book
- 책 검색으로 등록 · ISBN으로 등록 · 수동 등록(제목/저자만으로도 가능)

### Reading Session
- **Start Reading** / **Stop Reading**
- 독서 시간 자동 기록 (활성 세션은 즉시 저장 → 앱을 닫아도 유지)
- 시작 페이지 · 종료 페이지 (둘 다 선택)

### Place — "Where did you read?"
- 독서 종료 후 장소를 묻는다
- **기존 장소 선택** 또는 **새 장소 생성**
- 새 장소: 이름 입력 · (선택)지도에서 위치 지정 또는 현재 GPS · (선택)주소 자동 채움(reverse-geocode) · (선택)사진 첨부
- GPS·지도·사진은 **모두 선택**. 이름만으로도 장소 생성 가능.

### Journal
- **Book View** — 책 중심 타임라인 (이 책을 읽어온 기억들)
- **Place View** — 장소 중심 타임라인 (이곳에서 읽은 기억들)
- 개별 Memory 상세 (책 · 장소 · 시간 · 페이지 · 사진)

### Library
- 책 목록과 책별 요약: **총 독서시간 · 세션 수 · 읽은 장소들**

## 6. User Flow
**핵심 흐름 (독서 → 기억)**
```
책 선택(또는 빠른 추가) → [시작 페이지?] → Start Reading
      → (읽는 중: 조용한 경과 시간 화면, 백그라운드 유지)
      → Stop Reading → [종료 페이지?]
      → "어디서 읽으셨나요?" → 장소 선택 / 새 장소 → [사진?]
      → 기억 저장 ✓
```
**회상 흐름**
```
Journal → Book View / Place View → Memory 상세
Library → 책 선택 → 책별 통계 · 그 책의 세션들
```

## 7. MVP 범위
포함: Book(검색/ISBN/수동) · Session(시작·종료·시간·페이지) · Place(선택/생성·지도·GPS·사진·주소) · Journal(Book/Place View) · Library(책별 통계) · Sign in with Apple **더미 버튼**.

제외(=비목표): 목표·스트릭·gamification·경쟁·소셜·대시보드·알림 압박·통계 극대화 UI.
